# Веб-приложение для распределения студентов по командам (HR-helper)

Вместе с командой разрабатывал WEB-приложение для распределения студентов по командам (HR-helper).

Сервис позволяет студентам пройти тестирование и заполнить анкету, после чего при помощи нейросети YandexGPT, с учётом полученных данных, формируются сбалансированные команды с распределением ролей.  
Студенты взаимодействуют с сервисом через веб-интерфейс, а HR-специалисты - через Telegram-бота.

## В рамках проекта:
- Спроектировал структуру базы данных и реализовал её взаимодействие с приложением через Hibernate.
- Разработал REST API на Java с использованием Spring Boot.
- Настроил авторизацию и аутентификацию с помощью Keycloak.
- Реализовал асинхронное взаимодействие между микросервисами через брокер сообщений Kafka.
- Покрыл более 60% серверной логики unit-тестами.
- Настроил интеграцию с Telegram API для реализации HR-бота.
- Настроил интеграцию с YandexGPT API для реализации формирования команд.
- Развернул проект на VPS-сервере в Docker-контейнерах.
- Взаимодействовал с frontend-разработчиком для интеграции клиентской и серверной частей.

## Стек технологий:
Java 17, Spring Boot, Hibernate, PostgreSQL, Docker, Docker-compose, Keycloak, Kafka, JUnit, Mockito, React.
